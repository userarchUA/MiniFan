# MiniFan — управление кулером для Mac mini 2011 (macOS Catalina)

Красивое приложение (SwiftUI) + фоновая служба, которая через SMC меняет обороты вентилятора по кривой температуры.

## Установка
1. `xcode-select --install`  (один раз, если ещё нет Command Line Tools)
2. Распакуй папку, в Терминале: `cd ~/Downloads/MiniFan`
3. `./build.sh`
4. `sudo ./install.sh`
5. Открой **MiniFan** из «Программ».

Удаление: `sudo ./uninstall.sh` (вентилятор вернётся под управление системы).

## Возможности
- Профили Auto / Silent / Balanced / Performance / Max + свои
- Редактор кривой мышью, живой маркер текущей температуры
- Выбор датчиков, гистерезис, плавность разгона/спада, мин/макс, критическая температура
- Строка меню с температурой и оборотами, °F, автозапуск, Lite-режим для слабой графики
- Защита: нет датчиков → максимум; остановка службы → автоматика системы
